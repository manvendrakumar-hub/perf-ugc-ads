03 · Generation path, model rules and cost logic

Why the path is staged

  1. Build a try-on still first: a low-cost proof that identity and eyewear can coexist.
  2. Attach media differently per engine because Seedance permits one start image while Kling accepts a broader reference set.
  3. Rotate across three shot-list variants so multiple takes test different motion emphasis.
  4. Submit every take before polling so Higgsfield can execute concurrently.
still = _tryon_still(anchor, product, scene)
qc_refs = products[:2]

if model == "seedance_2_0":
    medias = [still or anchor]       # one start image
else:
    medias = [still or anchor, *qc_refs]

jobs = [submit(take) for take in specs]
videos = [poll_and_download(job) for job in jobs]
04 · Prompt gate, failures and automatic recovery

Before spending credits

  • Warn on brand names that may trigger ip_detected.
  • Replace known false-positive phrases such as “tight face”.
  • Guarantee an eyewear-fidelity lock is present.
  • Trim prompts below Kling’s documented character cap.
  • Retry NSFW/IP rejections up to the configured limit; other failures are logged per take without destroying successful siblings.
prompt = _prompt_gate(scene + shot_list, model)

for attempt in range(NSFW_RETRIES + 1):
    job_id = submit(prompt, medias)
    try:
        return wait(job_id)
    except Filtered as error:
        if error.kind not in {"nsfw", "ip_detected"}:
            raise
log("take failed; continue remaining jobs")

TH Tool—in depth.

A gated three-stage system: approve the idea, approve the footage, then let deterministic code finish the edit.

Script + stills→Gate 1→Talking + B-roll→Gate 2→Stitch→Voice + export
TH Tool · local runtimeView app.py ↗View orchestration ↗View stitcher ↗

What the buttons control

PID + character
Resolve product imagery, anchor and demographic voice.
Outfit + location
Build the visual prompt and reusable kit frame.
Script mode
Manual Claude Pattern 1 or randomized local Pattern 2.
Start Stage 1
Creates script, kit, try-on and two POV stills cheaply.
Approve Stage 2
Generates role-routed talking cuts plus four B-rolls.
Approve Stage 3
De-silences, overlays, revoices, checks drift and exports.

Why this approach

  • Human gates stop weak scripts and stills before video credits are spent.
  • Seedance handles the hook; Kling handles cost-efficient wearing and pose cuts.
  • Softened start frames reduce artificial skin texture.
  • Overlay compositing keeps A-roll frame-accurate while B-roll hides cuts.
  • ElevenLabs STS unifies voice timbre; forced alignment reports lip-sync drift.
01 · Three-stage application state

The gates are part of the architecture

  1. Stage 1: script, kit frame, try-on and POV stills.
  2. Gate 1: edit/approve the script and cheap visual foundation.
  3. Stage 2: talking cuts and four role-specific B-roll clips.
  4. Gate 2: review generated footage before assembly.
  5. Stage 3: stitch, voice, alignment report and final export.

02 · Script system, lint and cut packing

Two script lanes

  • Manual: Claude Pattern 1, editable at Gate 1, split into ≤46-word chunks.
  • Auto: one vision analysis followed by local randomized hook/open/middle/close banks.
  • Roles: first cut is hook, last is pose, middle cuts are wearing.
  • Lint: “Lenskart” becomes “Lens Kart”; origin cities fail; banned value language warns.
def assign_roles(cuts):
    for i, cut in enumerate(cuts):
        if i == 0: role = "hook"
        elif i == len(cuts)-1: role = "pose"
        else: role = "wearing"

05 · Stitch algorithm and zero-drift composition

Deterministic edit logic

  • Detect silence at −30dB for at least 0.3 seconds.
  • Keep 0.1-second pads and bridge tiny islands to avoid stutter flashes.
  • Build a continuous A-roll base from the kept ranges.
  • Start B-roll at 3 seconds, place 2-second windows every 3 seconds, rotate through every generated B-roll.
  • Overlay onto the base instead of concat-recutting, avoiding accumulated timing drift.
WINDOW_DUR = 2.0
WINDOW_SPACING = 3.0
t = 3.0
while t + 0.5 <= total:
    broll = brolls[i % len(brolls)]
    yield (t, min(WINDOW_DUR, total-t), broll, 2.0)
    t += WINDOW_SPACING

[base][broll]overlay=enable='between(t,start,end)'
06 · Voice pass, alignment and final output

One voice across mixed engines

  1. Extract the stitched A-roll audio.
  2. Resolve the character’s ElevenLabs voice or demographic default.
  3. Run speech-to-speech once across the full edit.
  4. Pad audio to picture length before -shortest; copy video without re-encoding.
  5. Force-align original and transformed speech against the script.
  6. Report drift; ≤60ms is OK, above it requires manual lip-sync review.
voice = voice_for_character(voice_key, group)
sts_audio = sts(source_audio, voice)
padded = ffmpeg_apad(sts_audio, whole_dur=video_duration)
mux(video, padded, video_codec="copy")

drift_ms = compare_alignment(original, sts_audio, script)
status = "OK" if drift_ms <= 60 else "CHECK LIP-SYNC"
